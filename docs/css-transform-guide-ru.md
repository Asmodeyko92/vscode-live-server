# CSS `transform`: большой практический гид с объяснениями

> Тема: свойство `transform` в CSS (по мотивам MDN Reference)
>
> Для кого: для новичка, который учится программировать и хочет **понять, что именно происходит в коде**.

---

## 1) Что такое `transform` простыми словами

`transform` — это свойство CSS, которое изменяет **геометрию отображения** элемента:

- двигает (`translate`),
- вращает (`rotate`),
- масштабирует (`scale`),
- наклоняет (`skew`),
- и позволяет комбинировать всё это в цепочки.

Важно: чаще всего `transform` **не меняет поток документа** (layout), а влияет на то, как элемент отрисовывается на этапе композиции.

### Мини-иллюстрация

Исходно:

```text
[ card ]
```

После `transform: translateX(40px);`:

```text
[ card ]  ---> (визуально сдвинут вправо)
```

В коде:

```css
.card {
  transform: translateX(40px);
}
```

---

## 2) Базовый синтаксис

```css
.selector {
  transform: none | <transform-function>+;
}
```

Где `<transform-function>` — это одна или несколько функций:

- `translate(...)`
- `rotate(...)`
- `scale(...)`
- `skew(...)`
- `matrix(...)`
- 3D-варианты: `translate3d`, `rotateX`, `rotateY`, `rotateZ`, `scale3d`, `matrix3d`, `perspective`

Пример цепочки:

```css
.box {
  transform: translateX(20px) rotate(15deg) scale(1.1);
}
```

### Что произойдёт по шагам

1. Элемент сдвинется на 20px вправо.
2. Затем повернётся на 15°.
3. Затем увеличится на 10%.

> Порядок важен! Если поменять функции местами, визуальный результат будет другим.

---

## 3) Почему порядок функций критичен

Сравним:

```css
/* Вариант A */
transform: translateX(100px) rotate(45deg);

/* Вариант B */
transform: rotate(45deg) translateX(100px);
```

Вариант A: сначала сдвиг, потом поворот вокруг точки трансформации.

Вариант B: сначала поворот осей элемента, затем сдвиг уже по «повёрнутой» оси X.

Иллюстрация (концептуально):

```text
A: [двинул] -> [повернул]
B: [повернул] -> [двинул по новой оси]
```

Для новичка правило такое:

- Читай цепочку `transform` **слева направо**, представляя каждую операцию по очереди.

## 4) Самые важные функции `transform`

## 4.1 `translate`

Перемещает элемент.

```css
.el-1 { transform: translateX(50px); }
.el-2 { transform: translateY(-20px); }
.el-3 { transform: translate(30px, 10px); }
```

- `X` — вправо/влево
- `Y` — вниз/вверх (в CSS положительный Y обычно вниз)

## 4.2 `rotate`

Поворачивает элемент.

```css
.el { transform: rotate(30deg); }
```

- `deg` — градусы
- положительное значение обычно вращает по часовой стрелке в 2D-координатах браузера

## 4.3 `scale`

Меняет размер.

```css
.el-1 { transform: scale(1.2); }      /* и X, и Y */
.el-2 { transform: scaleX(0.8); }     /* только X */
.el-3 { transform: scaleY(1.5); }     /* только Y */
```

- `1` = исходный размер
- `< 1` = уменьшение
- `> 1` = увеличение

## 4.4 `skew`

Наклоняет элемент (сдвиг углов).

```css
.el { transform: skew(10deg, 5deg); }
```

Используется реже, но полезно для «псевдо-изометрии» и декоративных эффектов.

---

## 5) `transform-origin`: вокруг какой точки всё крутится/масштабируется

По умолчанию трансформация идёт от центра элемента (`50% 50%`).

```css
.box {
  transform-origin: left top;
  transform: rotate(20deg);
}
```

Иллюстрация:

```text
По умолчанию:        С origin: left top:
   ↻ центр               ↻ левый верхний угол
```

Если анимация «ведёт себя странно», чаще всего стоит проверить `transform-origin`.

---

## 6) 2D и 3D: чем отличаются

2D: работа в плоскости X/Y.

3D: добавляется ось Z и перспектива.

Пример 3D-поворота:

```css
.scene {
  perspective: 600px;
}

.card {
  transform: rotateY(30deg);
}
```

- `perspective` задаёт ощущение глубины.
- Без перспективы 3D-эффект часто выглядит «плоско».

## 7) Практический пример карточки (hover-эффект)

```html
<div class="card">Наведи на меня</div>
```

```css
.card {
  width: 220px;
  padding: 24px;
  border-radius: 12px;
  background: #1f2937;
  color: white;
  transition: transform 240ms ease, box-shadow 240ms ease;
}

.card:hover {
  transform: translateY(-6px) scale(1.02);
  box-shadow: 0 14px 28px rgba(0, 0, 0, 0.22);
}
```

### Что здесь происходит

- `transition` говорит браузеру плавно анимировать изменение `transform`.
- На `:hover`:
  - `translateY(-6px)` поднимает карточку вверх,
  - `scale(1.02)` чуть увеличивает,
  - тень усиливает «подъём».

Это один из самых частых реальных паттернов в интерфейсах.

## 8) Важные технические нюансы

1. **`transform` создаёт новый stacking context** (контекст наложения).
   - Может неожиданно повлиять на `z-index`.

2. **Позиция в потоке не меняется**.
   - Соседи не «раздвигаются», даже если элемент визуально переехал.

3. **Производительность**.
   - Обычно анимации `transform` и `opacity` более «дружелюбны» к рендерингу, чем анимация `top/left/width`.

4. **Переполнение контейнера**.
   - Если родитель с `overflow: hidden`, увеличенный/повёрнутый элемент может обрезаться.

---

## 9) Как дебажить `transform`, если «что-то не так»

Чеклист:

- Проверь порядок функций в `transform`.
- Проверь `transform-origin`.
- Убедись, что не конфликтуют `transform` в разных классах (последний перезапишет предыдущий).
- В DevTools временно отключай функции по одной.
- Для 3D проверь, есть ли `perspective` у родителя.

## 10) Частые ошибки новичков

### Ошибка 1: ожидание, что `translate` сдвинет соседей

```css
.item { transform: translateX(100px); }
```

Соседи не перестроятся. Это визуальный сдвиг, а не изменение layout.

### Ошибка 2: «почему мои трансформации пропали?»

```css
.box { transform: translateX(20px); }
.box.active { transform: rotate(20deg); } /* перезаписало translate */
```

Решение: объединять функции в одном `transform`:

```css
.box.active { transform: translateX(20px) rotate(20deg); }
```

### Ошибка 3: «анимация дёргается»

Иногда помогает:

- сократить количество одновременно анимируемых свойств,
- использовать `transform` вместо геометрических layout-свойств,
- проверить тяжёлые тени/фильтры.

## 11) Короткая шпаргалка

```css
/* Сдвиг */
transform: translate(20px, 10px);

/* Поворот */
transform: rotate(15deg);

/* Масштаб */
transform: scale(1.1);

/* Наклон */
transform: skew(8deg, 0deg);

/* Комбинация */
transform: translateY(-4px) rotate(2deg) scale(1.03);

/* Точка трансформации */
transform-origin: left bottom;
```
